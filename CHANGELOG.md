# 更新日志 / Changelog

## v1.2.0 (2026-10-18)

- 新增:输入框上方的状态胶囊行(「后台 Bash」「目标」等胶囊所在行)追加「总结归档」
  胶囊按钮;该行不存在时在输入框上方自建同款布局的一行。点击后把固定提示词
  「将当前的所有对话进行总结，归档整理，方便交给其他 AI 继续处理」填入输入框,
  并自动点击原生发送按钮(与手动回车同一条发送路径),一键让 Kimi Code 总结归档
  当前对话、生成可交接给其他 AI 的归档文档。按钮复用全局 `.ui-pill` 样式,
  悬停显示仿原生 tooltip「总结归档，交接给其他 AI」。
  Added: a "总结归档" (summarize & archive) pill in the status pill row above the
  composer (the row holding "后台 Bash" / goal pills); when that row is absent the
  patch creates its own identically laid-out row above the composer. One click fills
  the composer with a fixed handoff prompt and clicks the app's native send button
  (the exact same path as pressing Enter), so Kimi Code summarizes and archives the
  current conversation into a handoff document for another AI to continue. The
  button reuses the global `.ui-pill` styles and shows a native-style tooltip.
- 修正(同日实测发现):渲染层**没有**全局 `.ui-pill` 规则,胶囊样式全部来自
  `.dock-workbar[data-v-30e8bc1b] .ui-pill` 这一条 scoped 规则;无胶囊行时按钮曾因此
  失去底色/圆角/内边距。现由补丁注入完整复刻样式(变量值带兜底),workbar 内仍让
  原生高优先级规则接管,两种场景外观一致。fixture 挂载真实 app 样式表对计算样式
  (圆角 10px / 底色 / 内边距 / 图标 18px / 行缩进 32px)逐项断言通过。
  Fix (found in same-day field testing): the renderer has no global `.ui-pill`
  rule — all pill styling comes from the single scoped rule
  `.dock-workbar[data-v-30e8bc1b] .ui-pill`, so without the pill row the button
  lost its background/radius/padding. The patch now injects a full replica of the
  styles (with fallback values); inside the pill row the higher-specificity native
  rule still wins, so both scenarios look identical. Computed-style assertions
  (radius 10px / background / padding / 18px icon / 32px row indent) pass against
  the app's real stylesheets in fixtures.
- 实现细节:tooltip 助手从引用按钮专用泛化为 `showTip(btn, text)`,两个功能共用。
  Internals: the tooltip helper was generalized from quote-only to
  `showTip(btn, text)` and is now shared by both features.

## v1.1.1 (2026-10-15)

- 引用按钮悬停提示改为仿原生 tooltip 气泡(文字「引用」),替换掉浏览器原生
  title 提示;样式复用 app 主题变量(--tooltip-bg/--tooltip-fg/--ms-radius 等),
  点击/移出即销毁。
  The quote button now shows a native-style tooltip bubble ("引用") on hover
  instead of the browser's default title tooltip; styled with the app's own
  theme variables and destroyed on click/mouseleave.

## v1.1.0 (2026-10-15)

- 新增:每条用户消息底部工具栏(复制/撤回/时间那一行)注入「引用」按钮,
  点击把该消息作为原生 quote pill 插入输入框;合成粘贴事件走 app 自身的
  ProseMirror 粘贴管道,quote markdown 语法与渲染层源码逐字对齐;
  粘贴失败时回退为插入纯文本。仅附件的消息引用附件名。
  Added: a "quote" button on every user message's footer toolbar (next to
  copy/undo/time); clicking inserts the message into the composer as a native
  quote pill via a synthetic paste event through the app's own ProseMirror
  paste pipeline, with the quote-markdown syntax byte-aligned to the renderer
  source; falls back to plain-text insertion if the paste does not land.
  Attachment-only messages quote the attachment names.
- 按钮样式复用原生 `.u-copy`,并从原生按钮上动态复制 `data-v-*` 作用域属性,
  跨前端版本不易走样。
  Button reuses the native `.u-copy` style and copies the `data-v-*` scope
  attribute from the native button at runtime, so it survives frontend
  re-scoping across app versions.
